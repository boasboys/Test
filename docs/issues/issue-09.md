# Issue 9 — The audit report: `tokenlens audit`

## Goal
The wedge feature. One command → shareable markdown/HTML report: total spend
(reconciled), cache-health distribution + top bust triggers with $ damage,
task-type waste breakdown (conversation/exploration $), fan-out summary, top 5
prescriptions ranked by recoverable $. Anonymized-by-default share mode.

## Acceptance criteria
- Golden-file test of the full report on the corpus.
- Every $ figure traceable to a component with a pricing-snapshot /
  divergence-ledger reference.
- Renders clean on all 5 golden fixtures.

## Human gate
The founder personally validates that the report on their own data reads true.

## Dependencies
All of Issues 1–8.
